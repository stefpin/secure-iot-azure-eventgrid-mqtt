Certificate Authority

Contoso runs its own CA. The three CA keys are RSA keys inside the Key Vault Premium HSM and never leave it - every certificate is signed there. The root key is disabled after it signed the two issuing CAs.

Retained Messages

The broker keeps the last retained message of each topic and hands it to every new subscriber immediately. Devices retain their status (online / offline via Last Will) and state; the fleet configuration is retained too, so a device that was offline gets it the moment it connects.
